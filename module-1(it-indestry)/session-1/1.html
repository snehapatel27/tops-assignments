1. Name 5 IT job roles and write one line about what each role does.

  1. Software Developer: Develops and maintains software applications.
  2. Web Developer: Builds and maintains websites and web applications.
  3. UI/UX Designer: Designs user-friendly and attractive interfaces.
  4. Data Analyst: Collects and analyzes data to support business decisions.
  5. Cyber Security Analyst: Protects computer systems and networks from cyber attacks.

Service Companies

3. Full Forms and Uses

  • GitHub: Git Hub - Used to store and manage source code.
  • Slack: Searchable Log of All Communication and Knowledge - Used for team communication.
  • Jira: Jira is not a full form - Used for project management and bug tracking.
  • IDE: Integrated Development Environment - Used to write and run code.
  • API: Application Programming Interface - Used for communication between software applications.

4. Programming Languages and Uses

  1. Python: Data Science and Machine Learning.
  2. Java: Android App Development.
  3. JavaScript: Web Development.
  4. C++: Game Development.

5. Difference Between Developer and Tester

Developer: Develops and maintains software applications.

Tester: Tests software to find bugs and ensure it works correctly.
