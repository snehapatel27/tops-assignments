1. Write the full form and one-line use of: HTTP, HTTPS, FTP, SMTP.

  • HTTP (HyperText Transfer Protocol): Used to transfer web pages between a browser and a web server.
  • HTTPS (HyperText Transfer Protocol Secure): Used to securely transfer data over the internet using encryption.
  • FTP (File Transfer Protocol): Used to upload and download files between computers.
  • SMTP (Simple Mail Transfer Protocol): Used to send email messages over the internet.

2. What is the difference between IPv4 and IPv6?

IPv4: Uses a 32-bit address and supports about 4.3 billion unique addresses.

IPv6: Uses a 128-bit address and supports a much larger number of unique addresses.

4. What do these HTTP status codes mean?

  • 200: OK – The request was successful.
  • 301: Moved Permanently – The page has been permanently moved to a new URL.
  • 404: Not Found – The requested page does not exist.
  • 500: Internal Server Error – The server encountered an unexpected error.
  • 403: Forbidden – Access to the requested resource is denied.

5. Explain DNS hierarchy with www.google.com as an example.

  • Root (.): The highest level of the DNS hierarchy.
  • TLD: .com is the Top-Level Domain.
  • Domain: google is the domain name.
  • Subdomain: www is the subdomain.

Example: www.google.com = www (Subdomain) + google (Domain) + .com (TLD).
